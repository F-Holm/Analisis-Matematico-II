## Cómo usar los ejercicios

Cada ejercicio tiene un botón **Solución** que muestra la respuesta. Dentro aparece otro botón, **Solución paso a paso**, con el desarrollo completo. Así se puede intentar resolverlo antes de mirar.

Los enunciados están copiados textualmente de la guía; cuando la [fe de erratas](aula-virtual/00-Guia-TP/Guia-TP-2016-Fe-de-Erratas-2018-07-31.pdf) corrige un ítem, la corrección aparece debajo del enunciado. Cuando una respuesta oficial o una resolución de la cátedra tiene un error, se aclara en el paso a paso.
